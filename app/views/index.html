{# ---- Generate CPS documents ---- #}

Generate CPS documents

{{ govukInsetText({ text: "Select any URN apart from the first in the task list to access the materials viewer Generate CPS documants flows" }) }}

Add and generate CPS documents across case, defendant and witness actors.

  • Case-level: factual summary, confidential information, action plan
  • Defendant: charge information, court orders, bail conditions, and others
  • Witness: documents linked to special measures decisions

Key implementation details:

  • Multi-select table pattern scoped per actor; checkbox IDs are unique per defendant to avoid collisions
  • POST body structured as defendants[id][documents] for multi-defendant selection
  • Check page uses GOV.UK summary list with per-actor sections, remove links, and returnUrl-aware change links
  • "Add another defendant / witness" links available from the check page
  • Document count shown before confirmation; generated cards added to the materials accordion on completion
{# ---- Charges ---- #}

Edit and substantial alteration of charges

{{ govukInsetText({ text: "Select any URN apart from the first in the task list to access all of the charge functionality in the Defendants tab " }) }}

Edit charge

  • Offence dates — single or multiple
  • Victim selection
  • Charge particulars
  • Check-and-confirm screen before changes are applied

Discontinue charge

End-to-end flow accessed from the action area in the Defendants tab.

  • Reason entry and check screen
  • Optional victim letter decision and set-reminder step
  • Charge status updates to Discontinued on completion
  • New reminder task prepended to the case overview task list if selected

Propose discontinuance

Two-step flow for formally proposing discontinuance to the police.

  • Reason entry and police reply-by date (MoJ date picker with quick-select shortcuts)
  • Check page before submission
  • Charge status updates to Discontinuance proposed; Propose button replaced by Revoke

Revoke proposal

  • Single confirmation screen to revoke a pending discontinuance proposal
  • Charge reverts to Put status; Propose discontinuance button reinstated
